A complete chess engine in 4,092 bytes of Python: negamax alpha-beta search with quiescence over captures, MVV-LVA move ordering and a procedural piece-square evaluation, run to a fixed node budget so every move is a pure function of the position and the trial replays move for move. It plays through the contest env at MAKEFUN_ENV_URL.

## Run it

```sh
python3 main.py
```
